# example-network

A module with one job and a clean interface: it computes subnet CIDRs from a
network CIDR and records the result. No cloud provider is involved, so it runs
anywhere with no credentials and no cost.

Everything below this line is generated by `terraform-docs` — do not edit it by
hand. Run `devbox terraform docs` to refresh, or `devbox terraform docs --check`
to verify it is current (which is what CI does).
